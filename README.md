# dealflows-keepalive

External cron pinger for **dealflows.net** (Houston Roof Claims production).

Hits `/api/health` every 5 minutes through GitHub Actions so the bounded public health check continues independently of an interactive workspace.

This pinger is a subordinate runtime/evidence component, not a controller. A successful health request does not prove auto-calling, revenue automation, CRM/customer workflows, provider delivery, or full production health. It may not restart another app, mutate customer data, send communications, or bypass an emergency stop.

## Why a separate public repo

- Keeps a narrowly scoped public endpoint check isolated from the private source repository.
- Contains no application or customer secrets.
- Makes the exact workflow revision and public response evidence independently reviewable.

## Safety

No secrets, authentication tokens, private endpoints, customer information, payment data, or business-control credentials belong in this public repository or its Actions logs. Any material change requires a canonical MASTER Work ID, lease, evidence contract, independent verifier, Closer, and writeback to #115.
